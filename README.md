# Волны любви — музыка

Сайт с музыкой из романов Роберта Фадера «Волны любви» и «Волны любви. Крепость в полумраке».
Треки разбиты по романам и идут в том порядке, в котором звучат в книгах; к каждому — сцена и строки из романа, к песням — их слова.
