# Волны любви — музыка

Сайт с мелодиями из романа Роберта Фадера «Волны любви. Крепость в полумраке».
Мелодии идут в том порядке, в котором звучат в книге; к каждой — сцена и строки из романа.

| № | Мелодия | Глава |
|---|---------|-------|
| 1 | Ночная мелодия | 3 |
| 2 | Крепость в полумраке | 5 |
| 3 | Волны любви | 7 |
| 4 | Рояль в стене | 10 |
| 5 | Музыка в плену | 15 |
| 6 | Мелодия, которая нашла дорогу | 18 |
| 7 | Мелодия повиновения | 21–22 |
| 8 | Волны любви — финал | 24 |
| 9 | Мелодия, которую нельзя забыть | 25 |

Добавить запись: положить mp3 в `audio/` с именем из `assets/js/treki.js` (например, `audio/03-volny-lyubvi.mp3`), указать `duration` и убрать `audio: false`.

Музыка: Луис Фадер.
